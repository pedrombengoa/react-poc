# Product Mission

## Purpose

Personal Finance Dashboard is a focused proof of concept for an Engineering Manager job search. It demonstrates that the author can use AI-assisted development to become productive in a new frontend stack, make sound engineering tradeoffs, and deliver a polished, tested, deployable product quickly.

## Audience

- **Primary audience:** engineering recruiters, hiring managers, and technical interviewers evaluating the author's product judgment, technical leadership, and ability to work effectively with React and modern AI tools.
- **Secondary audience:** people exploring a simple personal-finance dashboard using fictional data.

## Solution

Phase 1 opens directly into a public demo that anyone can explore without creating an account or signing in. Phase 2 adds real sign-up, login, logout, and persistent personal transactions. Phase 3 extends the product to a React Native mobile app. The demo showcases monthly income and spending, transaction trends, category charts, filters, and responsive layouts using fictional data.

## Product Principles

- Optimize for a recruiter understanding the product within the first minute.
- Keep public demo access account-free; account creation and sign-in are planned for Phase 2, not excluded from the product.
- Show real engineering judgment through clear boundaries, focused automated tests, secure data access, and cost-aware deployment.
- Prefer a small end-to-end product over production-scale breadth; this is a portfolio proof of concept, not financial advice or a banking product.
- Document where AI tools helped, what the author decided, and how generated work was verified.
